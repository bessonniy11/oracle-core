# Jira: Документация (Add Voices / Advanced TTS)

## Навигация

- `user-flow.md` — пользовательские сценарии (выбор/прослушивание голосов)
- `backend-spec.md` — спецификация бекенда и TTS‑сервиса
- `frontend-spec.md` — спецификация фронтенда
- `tasks.md` — этапы и чек‑листы работ

## Статус

- Текущий этап: PoC
- MVP: тестовый, non‑commercial
- Основной провайдер (PoC): Qwen3‑TTS (self‑hosted)
- Модель (PoC): 0.6B
- Язык (PoC): русский
- Формат аудио (PoC): mp3
- Fallback: системный TTS (Web Speech / FlutterTTS)

## Область PoC

- Выбор голоса из списка предустановленных
- Предпрослушивание коротких превью
- Озвучка ответов в чате
- Фолбэк на системный TTS при ошибках

Не входит в PoC:
- Клонирование голоса пользователя
- Voice design через описание
- Стриминг TTS

## Важные допущения

- Потребуется отдельный сервер с GPU (TBD по модели/VRAM)
- Юридические проверки отложены до этапа коммерциализации
- Нужна политика хранения аудио и текста (TTL, доступ, удаление)

## Решения (предварительные)

- Интеграция через отдельный TTS‑сервис (HTTP)
- Кэширование аудио на стороне сервиса
- Логи без пользовательского текста (PII‑safe)

## Открытые вопросы

- Целевые метрики: latency p95, качество, QPS
- Где хранить аудио: локально / S3‑совместимый бакет
- Нужны ли ограничения по имитации голоса в будущем

## Критерии готовности PoC

- Стабильный список голосов, доступный из UI
- Preview работает < 2s для коротких текстов (целевой ориентир)
- При падении TTS срабатывает фолбэк
- Аудио хранится ограниченно по TTL
