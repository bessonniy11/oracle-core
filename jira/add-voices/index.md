# Jira: Документация (Add Voices / Advanced TTS)

## Навигация

- `user-flow.md` — пользовательские сценарии (выбор/прослушивание голосов)
- `backend-spec.md` — спецификация бекенда и TTS‑сервиса
- `frontend-spec.md` — спецификация фронтенда
- `tasks.md` — этапы и чек‑листы работ

## Статус

- Текущий этап: подготовка спецификаций
- MVP: тестовый
- Основной провайдер (MVP): Qwen3‑TTS (self‑hosted)
- Язык (MVP): русский
- Формат аудио (MVP): mp3
- Fallback: системный TTS (Web Speech / FlutterTTS)

## Важные допущения

- Потребуется отдельный сервер с GPU (TBD по модели/VRAM)
- Лицензии моделей и веса требуют отдельного юридического подтверждения
