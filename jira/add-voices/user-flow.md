# User Flow: Advanced TTS (Add Voices) — MVP

## 1. Выбор голоса для персоны

1. Пользователь открывает настройки персоны
2. Видит список доступных голосов
3. Выбирает голос и сохраняет
4. Голос сохраняется в профиле персоны

## 2. Предпрослушивание

1. Пользователь нажимает «Прослушать»
2. Приложение запрашивает краткий preview у TTS
3. Воспроизводится аудио 2–5 секунд
4. Если TTS недоступен — fallback на системный голос

## 3. Ответ модели

1. Модель формирует ответ
2. Бекенд отправляет текст в TTS‑сервис
3. Возвращается `audioUrl` (или `audioBase64` в режиме dev)
4. Клиент воспроизводит аудио

## 4. Ошибки и фолбэк

1. Если TTS‑сервис недоступен
2. Отображается дружелюбное сообщение
3. Автоматически используется системный TTS
4. Ошибка логируется на бекенде

## 5. Деградация качества

1. Если перегрузка
2. Система снижает качество (TBD: модель/битрейт)
3. Пользователь не теряет функциональность

## 6. Приватность

1. Текст не хранится дольше необходимого
2. Аудио кэшируется ограниченно по TTL
3. Явно указаны сроки хранения
