# Frontend Spec: Advanced TTS (Add Voices) — MVP

## 1. Цели

- Дать пользователю выбор голосов
- Держать интерфейс простым
- Фолбэк на системный TTS при ошибках

## 2. UI и поведение

### 2.1 Настройки персоны
- Список голосов (название, язык, теги)
- Кнопка «Прослушать» для preview
- Сохранение выбора

### 2.2 В чате
- Озвучка ответа, если `audioUrl` есть
- Если нет `audioUrl` → системный TTS
- Кнопка «Стоп» для прерывания

## 3. Ошибки

- При недоступности TTS показывать уведомление
- Автоматически fallback на системный голос

## 4. Кэш

- Клиент не хранит аудио
- Повторное воспроизведение берется по URL

## 5. Тестовые кейсы

- Смена голоса в настройках
- Прослушивание preview
- Ошибка TTS → fallback
- Длинный ответ → корректная озвучка

## 6. UX детали

- Не автозапускать preview без явного действия
- Показывать индикатор загрузки при генерации preview
- Учитывать беззвучный режим и фоновые ограничения платформы
