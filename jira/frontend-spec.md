# Frontend Spec: Tools (Weather/News) — MVP

## 1. Цели

- Показать пользователю новости и погоду с источниками
- Сохранить простой UX
- Избежать «галлюцинаций» при ошибках

## 2. UI и поведение

- Обычный чат, без отдельного экрана
- В ответе для новостей показывать список заголовков + источник
- По запросу «подробнее» показывать краткое резюме и ссылку
- Если данные с задержкой, это явно указать в ответе

## 3. Режимы источников

- По умолчанию `mixed`
- Пользователь может явно указать «российские» или «мировые» в вопросе
- Если не указано явно, режим выбирается по смыслу запроса

## 4. Обработка ошибок

- Если инструмент недоступен, выводить понятное сообщение
- Модель не должна выдумывать факты при ошибке

## 5. Перевод/пересказ

- Для «мировых» новостей ответ на русском
- При необходимости помечать «перевод/пересказ» в тексте ответа

## 6. Кэширование

- На клиенте кэш не обязателен
- Повторные запросы решает бекенд

## 7. Тестовые кейсы

- «Погода в Пензе завтра»
- «Главные новости за сутки»
- «Российские новости»
- «Мировые новости»
- Ошибка провайдера
