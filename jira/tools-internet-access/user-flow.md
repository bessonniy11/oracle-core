# User Flow: Tools (Internet Access) — MVP

## 1. Вход в приложение

1. Пользователь открывает приложение
2. Видит текущий чат и выбранную персону
3. Может выбрать персону в настройках

## 2. Запрос погоды

1. Пользователь вводит вопрос: «Какая погода в моем городе завтра?»
2. Модель понимает намерение «погода» и вызывает инструмент погоды
3. Ответ отображается кратко, с ключевыми параметрами
4. При необходимости показывается источник данных

## 3. Запрос новостей

1. Пользователь вводит: «Главные новости за сутки»
2. Модель вызывает инструмент новостей
3. Возвращается список заголовков с источниками
4. Пользователь может попросить подробнее по конкретной новости
5. Если есть задержка данных, это явно отображается

## 4. Семантический выбор источников

1. По умолчанию «смешанный» режим источников
2. Модель выбирает режим по смыслу запроса
3. Пример: «что там в российских новостях» → режим `ru`
4. Пример: «что там в мировых новостях» → режим `international`
5. Ответ содержит явное указание источника
6. Новости из зарубежных источников возвращаются на русском (пересказ/перевод)

## 5. Курсы валют

1. Пользователь вводит: «Курс доллара к рублю» или «Курсы на сегодня»
2. Модель вызывает инструмент курсов валют
3. Возвращается список курсов и время обновления
4. Источник данных отображается явно

## 6. Отложено до следующей итерации

1. Транспорт/расписания — вне MVP
2. Места/рестораны — вне MVP

## 8. Ошибки и фолбэк

1. Если внешний источник недоступен, показывается дружелюбная ошибка
2. Модель предлагает повторить запрос позже
3. Никаких «галлюцинаций» без данных
