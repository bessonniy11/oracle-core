# Jira: Документация MVP (Tools: Weather/News)

## Навигация

- `user-flow.md` — пользовательские сценарии (погода/новости)
- `backend-spec.md` — спецификация бекенда и инструментов
- `frontend-spec.md` — спецификация фронтенда
- `tasks.md` — этапы и чек‑листы работ

## Статус

- Текущий этап: подготовка спецификаций
- MVP: тестовый
- Новости: смешанный режим источников
- Провайдеры MVP: Open‑Meteo (weather), GNews (news)
- Инструменты MVP: погода, новости, курсы валют, транспорт/расписания, места/рестораны
- Выбор режима новостей: по смыслу запроса (без UI‑переключателя)
