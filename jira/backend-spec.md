# Backend Spec: Tools (Weather/News) — MVP

## 1. Цели

- Дать модели доступ к погоде и новостям через контролируемые инструменты
- Сохранять безопасность, ограничивать доступ и стоимость
- Возвращать нормализованные ответы

## 2. Провайдеры (MVP)

- Погода: Open‑Meteo
  - Free для non‑commercial, без API‑ключа
  - Требуется атрибуция (CC BY 4.0)
  - Лимиты free API: до 10k/day, 5k/hour, 600/min
- Новости: GNews API Free
  - Только dev/test
  - 100 запросов/день, до 10 статей на запрос
  - 12‑часовая задержка
  - 1 запрос/сек

## 3. Архитектура

1. Модель не ходит в интернет напрямую
2. Модель вызывает инструменты через бекенд
3. Бекенд обращается к провайдерам, нормализует результат и возвращает модели

## 4. Инструменты

### 4.1 get_weather

Входные параметры:
- `location` (город/регион)
- `date` (YYYY‑MM‑DD, опционально)
- `units` (metric, по умолчанию)
- `lang` (ru‑RU)

Выход:
- `location`
- `date`
- `summary`
- `temperature` (min/max)
- `precipitation`
- `wind`
- `source`

### 4.2 get_news

Входные параметры:
- `query` (строка)
- `mode` (mixed | ru | international)
- `lang` (ru)
- `limit` (по умолчанию 5)

Выход:
- `items[]`:
  - `title`
  - `source`
  - `url`
  - `publishedAt`
  - `summary` (если доступно)

## 4.3 Семантический выбор режима

1. Если запрос содержит «российск», «РФ», «Россия» → `mode=ru`
2. Если запрос содержит «миров», «международн», «зарубеж» → `mode=international`
3. Иначе → `mode=mixed`

## 4.4 Перевод/пересказ

1. Для `mode=international` итоговый ответ пользователю на русском
2. Допускается краткий пересказ вместо полного перевода

## 5. Ограничения MVP

- Новости могут приходить с задержкой
- Использование бесплатного плана только для dev/test
- Обязательное отображение источника в ответе

## 6. Безопасность и ограничения

- Белый список инструментов
- Таймауты для внешних запросов
- Лимиты на количество новостей
- Логи ошибок и метрики
- Кэширование (in‑memory TTL)

## 7. Конфигурация (ENV)

- `WEATHER_PROVIDER=open-meteo`
- `NEWS_PROVIDER=gnews`
- `NEWS_API_KEY=...`
- `NEWS_DEFAULT_LANG=ru`
- `NEWS_DEFAULT_MODE=mixed`
- `TOOLS_TIMEOUT_MS=15000`
- `TOOLS_CACHE_TTL_SEC=300`

## 8. Ошибки

- При ошибке инструмент возвращает структурированную ошибку
- Модель обязана сообщать пользователю о недоступности данных

## 9. Тесты

- Unit: валидация параметров
- Unit: нормализация ответа
- E2E: запрос погоды и новостей
