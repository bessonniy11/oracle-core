# Oracle Core: Персонализированный AI Чат-робот

## О проекте
"Oracle Core" — это амбициозный проект по созданию кастомизируемого AI голосового чат-робота. Основная идея заключается в том, чтобы дать пользователю полный контроль над поведением и "личностью" его AI-ассистента.

## Цель проекта
Наша главная цель — разработать гибкую платформу, позволяющую настроить AI-ассистента под различные нужды и роли. Пользователь сможет определять различные "персоны" (например, "Афина" для помощи в программировании, "Фортуна" для юмористических бесед), задавать им уникальные правила, промты и обучать их в процессе диалога. Мы стремимся создать не просто голосового помощника, а интеллектуального компаньона, который адаптируется под пользователя и его задачи.

## Текущий этап
На данный момент мы находимся на этапе проектирования и разработки основной логики системы без привязки к физическому устройству. Это позволит нам тщательно отладить функционал управления персонами, правилами, контекстом диалогов и интеграцией с AI-моделью.
