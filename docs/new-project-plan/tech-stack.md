# Oracle Core: Стек Технологий

Данный документ описывает стек технологий, выбранный для разработки проекта "Oracle Core" в рамках новой архитектуры монорепозитория.

## I. Обзор Архитектуры

Проект "Oracle Core" реализуется как монорепозиторий, разделенный на два основных компонента: `backend` (бэкенд) и `frontend` (фронтенд), управляемые как Git-подмодули.

```
.
└── oracle-core/ (Корневой репозиторий)
    ├── docs/
    ├── package.json
    ├── .gitmodules
    ├── projects/
    │   ├── frontend/ (Git Submodule - Flutter App)
    │   └── backend/  (Git Submodule - Node.js Backend)
    └── README.md
```

## II. Backend (Node.js)

Бэкенд будет отвечать за всю серверную логику, взаимодействие с AI-моделями, управление данными (персоны, правила, история чатов) и предоставление API для фронтенда.

*   **Язык программирования:** JavaScript / TypeScript (предпочтительно TypeScript для большей типобезопасности и масштабируемости).
*   **Среда выполнения:** Node.js
*   **Веб-фреймворк:**
    *   **Начальный выбор:** Express.js (для простоты и быстроты старта).
    *   **Возможное расширение:** NestJS (для более крупных и сложных приложений, с акцентом на архитектуру и паттерны).
*   **База данных:** PostgreSQL (для надежного хранения структурированных данных).
*   **ORM/ODM:** Sequelize (для PostgreSQL, если используем Express.js) или TypeORM (если перейдем на NestJS с TypeScript).
*   **AI API:** Google Gemini API (для первоначального тестирования и работы с мощными языковыми моделями).
*   **Управление переменными окружения:** `dotenv`.
*   **Обработка CORS:** `cors` middleware.
*   **Аутентификация/Авторизация:** (Будет определено позже, по мере развития проекта. Возможно, JWT).
*   **Тестирование:** Jest / Mocha.

## III. Frontend (Flutter)

Фронтенд будет представлять собой кроссплатформенное мобильное и веб-приложение, обеспечивающее пользовательский интерфейс, голосовое и текстовое взаимодействие.

*   **Язык программирования:** Dart.
*   **Фреймворк:** Flutter (для создания нативных приложений для Android, iOS и веб-приложений из одной кодовой базы).
*   **Управление состоянием:** Provider, Riverpod или BLoC (будет выбран наиболее подходящий по мере проектирования UI).
*   **HTTP-клиент:** `http` package или `Dio` (для взаимодействия с бэкендом).
*   **Голосовой ввод (Speech-to-Text - STT):**
    *   **Мобильные платформы:** Встроенные возможности платформы (например, `speech_to_text` package).
    *   **Веб:** Web Speech API (через плагины Flutter).
    *   **Альтернатива/дополнение:** Google Cloud Speech-to-Text API (через бэкенд, если потребуется более высокая точность или языковые возможности).
*   **Голосовой вывод (Text-to-Speech - TTS):**
    *   **Мобильные платформы:** Встроенные возможности платформы (например, `flutter_tts` package).
    *   **Веб:** Web Speech API (через плагины Flutter).
    *   **Альтернатива/дополнение:** Google Cloud Text-to-Speech API (через бэкенд, для более качественных голосов).
*   **Анимации:** Встроенные возможности Flutter (для смайлика, переходов).
*   **Иконки:** Material Design Icons / Cupertino Icons.
*   **Локализация:** `flutter_localizations`.
*   **Тестирование:** `flutter_test`.

## IV. Дополнительные Технологии и Инструменты

*   **Система контроля версий:** Git.
*   **Хостинг репозиториев:** GitHub.
*   **Инструмент для монорепозитория:** Git Submodules (текущий выбор).
*   **IDE:** Visual Studio Code (для Node.js), Android Studio / VS Code (для Flutter).
*   **Управление пакетами:** npm / yarn (для Node.js), pub (для Flutter).
*   **Документация:** Markdown, JSDoc (для JavaScript/TypeScript).

Этот стек обеспечит гибкость, масштабируемость и кроссплатформенность, необходимые для проекта "Oracle Core".
