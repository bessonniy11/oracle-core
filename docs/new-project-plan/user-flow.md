# Oracle Core: Детальный пользовательский поток (User Flow) и описание экранов

Данный документ описывает подробный пользовательский поток приложения "Oracle Core", а также детальное описание и визуализацию каждого экрана с точки зрения пользователя.

## I. Введение
"Oracle Core" — это персонализированный AI голосовой чат-робот, который будет доступен как мобильное приложение (Flutter: Android/iOS), так и в браузере (Flutter Web). Приложение предоставляет пользователю возможность гибкой настройки AI-ассистента через различные "персоны" (роли), динамические правила и контекстное взаимодействие. Основной акцент сделан на интуитивный голосовой и текстовый ввод, а также на визуализацию эмоционального состояния AI через анимированный смайлик.

## II. Общий пользовательский поток

1.  **Запуск приложения:** Пользователь запускает приложение.
2.  **Экран загрузки/Сплеш-скрин:** Отображается краткий экран загрузки или сплеш-скрин.
3.  **Главный экран (Экран чата):** Пользователь попадает на главный экран, где виден анимированный смайлик, имя активной персоны, текст последнего ответа модели (если есть история) и поле ввода сообщения.
4.  **Взаимодействие с AI:**
    *   **Голосовой ввод:** Пользователь произносит имя персоны (например, "Афина", "Фортуна", "Оракл") для активации голосового диалога или специальных команд.
    *   **Текстовый ввод:** Пользователь вводит текст в поле ввода и отправляет его.
5.  **Навигация по приложению:**
    *   **Боковая шторка (Чаты):** Пользователь открывает боковую шторку для просмотра, создания, выбора и удаления чатов.
    *   **Настройки:** Пользователь переходит на экран настроек для управления персонами и их правилами.
6.  **Управление персонами и правилами:** На экране настроек пользователь может:
    *   Создавать новые персоны.
    *   Редактировать существующие персоны (имя, системный промт, правила).
    *   Удалять персоны.
    *   Добавлять/редактировать/удалять динамические правила для конкретной персоны.
7.  **Просмотр истории чата:** На главном экране можно прокручивать историю текущего чата.

## III. Описание экранов и их элементов

### 1. Экран загрузки / Сплеш-скрин
Этот экран будет отображаться при запуске приложения, пока происходит инициализация бэкенда (если это локальный режим) или загрузка основных ресурсов.

**Визуализация:**
```
+------------------+
|                  |
|     Oracle       |
|      Core        |
|                  |
|    [  Логотип  ]   |
|                  |
|    Загрузка...   |
|                  |
+------------------+
```
*   **Элементы:** Логотип приложения, название "Oracle Core", текст "Загрузка..." или индикатор прогресса.
*   **Поведение:** Длится несколько секунд, затем автоматически переключается на Главный экран.

### 2. Главный экран (Экран чата)
Это основной экран взаимодействия с AI-ассистентом.

**Визуализация (на основе твоей схемы):**
```
+---------------------------------+
| [☰]                 [⚙︎]        |  <-- Иконка шторки (меню), Иконка настроек
|                                 |
|         Афина                   |  <-- Имя активной персоны
|         +-----------+           |
|         |  ☺ Смайлик |           |  <-- Анимированный смайлик-аватар
|         +-----------+           |
|                                 |
|  -----------------------------  |  <-- Текст ответа модели
|  -------------------- --------- |  (Прокручиваемая история чата)
|  ------------- ---------------- |
|  -----------------------------  |
|  -----------------------------  |
|                                 |
| [ Введите ваше сообщение...   [>] ] |  <-- Поле ввода сообщения и кнопка "Отправить"
+---------------------------------+
```
*   **Элементы:**
    *   **Иконка шторки (☰):** В левом верхнем углу. При нажатии открывает Экран управления чатами.
    *   **Иконка настроек (⚙︎):** В правом верхнем углу. При нажатии переходит на Экран настроек.
    *   **Имя активной персоны:** Над смайликом. Показывает текущую персону (например, "Афина", "Фортуна", "Оракл"). При смене персоны имя обновляется.
    *   **Смайлик-аватар:** Центральный, крупный элемент. Анимируется, выражая эмоции модели в зависимости от тона диалога.
    *   **Текст ответа модели:** Область под смайликом, отображающая последний ответ AI. Это прокручиваемая область, позволяющая просматривать всю историю текущего чата.
    *   **Поле ввода сообщения:** В нижней части экрана. Для текстового ввода.
    *   **Кнопка "Отправить" ([>]):** Рядом с полем ввода. Для отправки текстового сообщения.
*   **Поведение:**
    *   При получении ответа от AI, текст отображается в области ответов, и смайлик анимируется в соответствии с тоном ответа.
    *   При прокрутке истории чата, смайлик остается на месте, меняется только текст.
    *   Голосовой ввод активируется по ключевым словам (имя персоны, "Оракл", "новое правило", "новый чат").
    *   Ограничения ввода: длина текстового сообщения ограничена (например, до N символов), аудио — по длительности/размеру файла. При превышении показывается подсказка.
    *   Кнопка "Отправить" переходит в статус "Отмена" во время генерации ответа, позволяя остановить TTS/рендер и запрос.

#### 2.1. Эмоции смайлика-аватара
Смайлик будет выражать различные эмоции, чтобы сделать взаимодействие более живым.

**Визуализация и описание:**

*   **Обычное/Нейтральное:**
    ```
    +-----------+
    |  ☺ (нейтрал) |
    +-----------+
    ```
    *   **Описание:** Глаза открыты, рот слегка изогнут в легкой улыбке. Используется по умолчанию или при нейтральных ответах.
*   **Радость/Одобрение:**
    ```
    +-----------+
    |  😄 (счастье) |
    +-----------+
    ```
    *   **Описание:** Глаза широко открыты, рот широко улыбается. Используется при получении похвалы, комплиментов или при генерации позитивных, юмористических ответов (например, Фортуна).
*   **Злость/Недовольство:**
    ```
    +-----------+
    |  😠 (злость) |
    +-----------+
    ```
    *   **Описание:** Брови нахмурены (если есть), рот изогнут в гримасе недовольства. Используется при получении агрессивных, оскорбительных сообщений (если модель распознает негатив) или если пользователь говорит что-то неприятное.
*   **Грусть/Разочарование:**
    ```
    +-----------+
    |  😞 (грусть) |
    +-----------+
    ```
    *   **Описание:** Глаза опущены, рот изогнут вниз. Используется при распознавании грустных или разочарованных сообщений от пользователя.
*   **Мысль/Ожидание:**
    ```
    +-----------+
    |  🤔 (думает) |
    +-----------+
    ```
    *   **Описание:** Одна бровь поднята, рука у подбородка или небольшие "точки" над головой. Используется, когда модель обрабатывает запрос и ожидает ответа от сервера (помимо мигающих точек).
*   **Удивление:**
    ```
    +-----------+
    |  😮 (удивление) |
    +-----------+
    ```
    *   **Описание:** Глаза широко раскрыты, рот открыт в форме "О". Используется при получении неожиданных или поразительных запросов/информации.
*   **Сосредоточенность (для Афины):**
    ```
    +-----------+
    |  🧐 (фокус) |
    +-----------+
    ```
    *   **Описание:** Глаза прищурены, возможно, очки. Используется, когда Афина обрабатывает сложный технический запрос.

### 3. Экран управления чатами (Шторка)
Открывается по нажатию иконки "☰" слева сверху на Главном экране.

**Визуализация:**
```
+------------------+
|  Oracle Core     |  <-- Заголовок
|  ---------------- |
|  [+] Новый чат   |  <-- Кнопка "Новый чат"
|  ---------------- |
|  [X] Чат с Афиной |  <-- Список существующих чатов (может быть иконка для удаления)
|  [X] Чат с Фортуной|
|  [X] Чат с Ораклом|
|  ---------------- |
|  [X] Чат с ...    |
|                  |
|                  |
+------------------+
```
*   **Элементы:**
    *   **Заголовок:** "Мои чаты" или "Oracle Core".
    *   **Кнопка "Новый чат":** Для создания нового пустого чата. При создании нового чата, сначала нужно выбрать персону.
    *   **Список чатов:** Перечень всех сохраненных чатов, возможно с именем персоны, с которой велся диалог. Каждый элемент списка:
        *   Название чата (например, "Чат с Афиной", "Чат по Python").
        *   Кнопка или иконка для удаления чата.
*   **Поведение:**
    *   При выборе чата из списка, Главный экран обновляется с историей выбранного чата.
    *   При нажатии "Новый чат", открывается диалог выбора персоны для нового чата.
    *   При удалении чата, он исчезает из списка. Перед удалением показывается подтверждение.
    *   Если чатов нет — показать пустое состояние ("У вас пока нет чатов") и CTA "Создать чат".

### 4. Экран настроек
Открывается по нажатию иконки "⚙︎" справа сверху на Главном экране.

**Визуализация:**
```
+---------------------------------+
| < Настройки                     |  <-- Кнопка "Назад", Заголовок "Настройки"
|                                 |
|  ## Персоны                     |
|  -----------------------------  |
|  [+] Добавить новую персону     |  <-- Кнопка "Добавить персону"
|  -----------------------------  |
|  > Афина (редактировать)        |  <-- Список существующих персон
|  > Фортуна (редактировать)      |  (по нажатию открывается Экран создания/редактирования персоны)
|  > Оракл (по умолчанию)         |
|                                 |
|  -----------------------------  |
|  [  Сохранить все изменения  ]  |  <-- Кнопка сохранения (если нужно)
|                                 |
+---------------------------------+
```
 *   **Элементы:**
    *   **Кнопка "Назад":** В левом верхнем углу. Возвращает на Главный экран.
    *   **Заголовок:** "Настройки".
    *   **Заголовок раздела "Персоны".**
    *   **Кнопка "Добавить новую персону":** Переходит на Экран создания/редактирования персоны для новой персоны.
    *   **Список существующих персон:** Каждый элемент списка:
        *   Имя персоны.
        *   Индикатор "по умолчанию" для дефолтной персоны.
        *   При нажатии на элемент открывается Экран создания/редактирования персоны для выбранной персоны.
    *   **Пустое состояние:** Если персон нет — текст "Добавьте первую персону" и CTA "Создать".
    *   **Настройки голоса (TTS):** Выбор одного из системных голосов устройства/браузера (мужской/женский, тон/скорость), кнопка предпрослушивания и сохранение выбора.
 *   **Поведение:**
    *   Позволяет управлять всеми персонами в системе.

#### 4.1. Экран создания/редактирования персоны
Открывается из Экрана настроек при добавлении новой персоны или редактировании существующей.

**Визуализация:**
```
+---------------------------------+
| < Назад к Настройкам            |  <-- Кнопка "Назад"
|                                 |
|  ## Редактировать персону: Афина|  <-- Заголовок (или "Создать новую персону")
|  -----------------------------  |
|  Имя персоны: [ Афина         ] |  <-- Поле для ввода имени персоны
|  -----------------------------  |
|  Системный промт:               |
|  [ Ты - опытный помощник...   ] |  <-- Текстовое поле для системного промта
|  -----------------------------  |
|  ## Настройки голоса (TTS)      |  <-- Новый раздел: Выбор голоса для этой персоны
|  [ Выбрать голос... ] [ 🔊 ]     |  <-- Выбор голоса и кнопка предпрослушивания
|  -----------------------------  |
|  ## Динамические правила        |
|  [+] Добавить новое правило     |  <-- Кнопка "Добавить правило"
|  -----------------------------  |
|  - [Правило 1 (редактировать)]  |  <-- Список правил с возможностью редактирования/удаления
|  - [Правило 2 (редактировать)]  |
|                                 |
|  [ Сохранить изменения      ]  |  <-- Кнопка "Сохранить"
|  [ Удалить персону          ]  |  <-- Кнопка "Удалить" (только для существующих персон)
+---------------------------------+
```
*   **Элементы:**
    *   **Кнопка "Назад":** Возвращает на Экран настроек.
    *   **Заголовок:** "Редактировать персону: [Имя]" или "Создать новую персону".
    *   **Поле ввода "Имя персоны":** Для изменения/указания имени.
    *   **Текстовое поле "Системный промт":** Для редактирования базовой инструкции AI.
    *   **Заголовок раздела "Настройки голоса (TTS)".**
    *   **Выбор голоса персоны:** Выпадающий список или аналогичный элемент для выбора одного из системных голосов устройства/браузера (мужской/женский, тон/скорость), с кнопкой предпрослушивания. Если не выбран, используется глобальная настройка.
    *   **Заголовок раздела "Динамические правила".**
    *   **Кнопка "Добавить новое правило":** Добавляет пустое поле для ввода нового правила.
    *   **Список правил:** Каждое правило отображается в виде текстового поля, которое можно редактировать, и кнопки для его удаления.
    *   **Кнопка "Сохранить изменения":** Сохраняет все изменения в персоне.
    *   **Кнопка "Удалить персону":** Удаляет текущую персону (недоступно для персоны по умолчанию).
    *   **Пустое состояние правил:** Если правил нет — текст "Нет правил" и CTA "Добавить правило".
*   **Поведение:**
    *   Сохраняет изменения в бэкенде.
    *   При удалении персоны, чаты с ней могут быть помечены как "архивные" или ассоциированы с персоной по умолчанию.
    *   Перед удалением персоны — подтверждение.

## IV. Сценарии голосового взаимодействия

### Сценарий 1: Начало диалога с определенной персоной
*   **Действие пользователя:** Пользователь говорит "Афина, <что-то спрашивает>".
*   **Поведение приложения:**
    *   Приложение распознает ключевое слово "Афина".
    *   Активирует персону "Афина" (если она не была активна).
    *   Записывает аудио, преобразует его в текст (STT).
    *   Отправляет текстовый запрос на бэкенд.
    *   Показывает индикатор набора текста (смайлик думает).
    *   Получает ответ от AI, преобразует его в голос (TTS) и воспроизводит.
    *   Отображает ответ на экране, смайлик анимируется.
    *   Запоминает диалог в истории чата с Афиной.

### Сценарий 2: Начало диалога с персоной по умолчанию ("Оракл")
*   **Действие пользователя:** Пользователь говорит "Оракл, <что-то спрашивает>".
*   **Поведение приложения:** Аналогично Сценарию 1, но активируется персона "Оракл".

### Сценарий 3: Добавление нового правила голосом
*   **Действие пользователя:** Пользователь говорит "Афина, новое правило <текст правила>".
*   **Поведение приложения:**
    *   Приложение распознает имя персоны "Афина" и команду "новое правило".
    *   Записывает аудио, преобразует в текст.
    *   Парсит сообщение, извлекая "текст правила".
    *   Отправляет запрос на бэкенд для добавления правила к персоне "Афина".
    *   Получает подтверждение от AI (например, "Поняла, Афина. Я запомнила правило..."), преобразует в голос и воспроизводит.
    *   Обновляет список правил для Афины в настройках.

### Сценарий 4: Создание нового чата голосом
*   **Действие пользователя:** Пользователь говорит "Афина, новый чат".
*   **Поведение приложения:**
    *   Приложение распознает имя персоны "Афина" и команду "новый чат".
    *   Создает новый пустой чат с персоной "Афина".
    *   Переключает Главный экран на этот новый чат.
    *   Модель может ответить: "Начинаю новый чат с Афиной. Чем могу помочь?"

### Сценарий 5: Продолжение текстового диалога
*   **Действие пользователя:** Пользователь вводит текст в поле ввода и нажимает "Отправить".
*   **Поведение приложения:**
    *   Отправляет текстовый запрос на бэкенд, используя текущую активную персону и историю чата.
    *   Показывает индикатор набора текста (смайлик думает).
    *   Получает ответ от AI.
    *   Отображает ответ на экране, смайлик анимируется.
    *   Запоминает диалог в истории текущего чата.

### Сценарий 6: Просмотр истории чата
*   **Действие пользователя:** Пользователь прокручивает область текста ответов модели на Главном экране.
*   **Поведение приложения:**
    *   Текст прокручивается, позволяя просмотреть предыдущие сообщения в текущем чате. Смайлик остается статичным или меняет эмоции в зависимости от последнего видимого сообщения.

### Сценарий 7: Ошибки и оффлайн
*   **Действие пользователя:** Любой из сценариев 1–6.
*   **Поведение приложения:**
    *   **Потеря сети/таймаут:** Показать статус "Оффлайн/Повторить", кнопки "Повторить" и "Переключиться на текст". Сообщение сохраняется локально как черновик.
    *   **STT ошибка/длинное аудио:** Подсказка "Не удалось распознать" / "Сократите запись до N сек", предложить ввод текста.
    *   **TTS ошибка:** Отобразить текстовый ответ, предложить повторить воспроизведение или выключить звук.
    *   **AI/бэкенд ошибка (5xx) или 401/403:** Сообщить кратко ("Сервис недоступен", "Требуется вход"), без технических деталей. Кнопки: "Повторить", "Выбрать другую персону", "Войти".
    *   **Ограничения:** При превышении лимита символов/аудио — подсказка и блок отправки, пока пользователь не сократит запрос.

### Сценарий 8: Управление длинными чатами и историей
*   **Действие пользователя:** Просмотр старых сообщений и чатов.
*   **Поведение приложения:**
    *   История чата подгружается лениво (пагинация/дозагрузка при прокрутке вверх).
    *   Фильтр/поиск по текущему чату и по персоне.
    *   Кнопка "К последнему сообщению".
    *   Пустое состояние истории: "Сообщений пока нет" + CTA отправить первое сообщение.

## V. Голосовые команды и горячие слова (минимальный набор)
*   **"Оракл/Афина/Фортуна, новый чат"** — создаёт новый чат с выбранной персоной.
*   **"Оракл/Афина/Фортуна, новое правило <текст>"** — добавляет правило активной персоне.
*   **"Смени персону на <имя>"** — переключает активную персону и обновляет имя над смайликом.
*   **"Стоп"/"Отмена"** — останавливает текущий ответ/воспроизведение TTS.
*   **Неизвестная команда:** короткая подсказка с примерами доступных команд.
